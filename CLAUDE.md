# Color Cafe — Claude working rules

Sister app to Puzzle Parlor (`KandyPhoenix/puzzle-parlor`). Reuse its conventions where they fit:
Cloudflare Pages, single-file canvas app, license codes, weekly content releases, "all sales final".

Content rules (same as Puzzle Parlor): only original or generated art Kandy owns; no real logos,
trademarked characters, real people, or copyrighted quotes/lyrics. Every line of text in a page
is spell-checked at full size before it ships.

## Agent skills

### Issue tracker

Issues live as markdown files under `.scratch/` (local tracker, until the GitHub repo is reachable). See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
